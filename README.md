# RPS Battlegrounds

一个带有 Rogue 成长系统的联机石头剪刀布桌面游戏。

当前版本已经具备完整的桌面游玩流程：

- 图形化主界面
- 房主创建房间并自动加入
- 玩家通过 IP + 端口联机加入
- 联机大厅等待、房间人数展示、地址复制
- 战斗阶段出拳与战斗道具选择
- 商店阶段购买、刷新、结束回合
- 游戏结束结算页
- 阵营视觉资源、角色立绘、主视觉横幅
- 页面整体可滚动，小窗口下也能查看战报日志
- macOS `.app` 打包脚本

## 游戏内容

`RPS Battlegrounds` 的核心循环是：

1. 创建房间或加入房间
2. 房间满员后自动开始
3. 进入一场对战
4. 结算胜负、掉血与经济
5. 进入商店成长
6. 重复以上流程，直到只剩最后一名存活玩家

### 对战规则

- 每场对战最多进行 `5` 个小局
- 先拿到 `3` 分的玩家直接赢下本场
- 如果打满 `5` 个小局，则比分更高的一方获胜
- 石头克剪刀，剪刀克布，布克石头
- 本场胜者会按照自己的 `攻击力` 对败者造成伤害
- 生命值降到 `0` 的玩家会被淘汰

### 成长与商店

- 每个大回合结束后，存活玩家都会进入商店
- 玩家会获得基础金币、连胜/连败收益和利息收益
- 可以购买道具与天赋，强化拳袋、经济、伤害或对战效果
- 商店支持刷新，也可以直接结束商店阶段

### 阵营说明

当前版本包含三个阵营：

- `磐岩壁垒`
- `迅刃风暴`
- `秘纸教团`

阵营会同步到大厅、局内档案卡与结算展示，同时提供轻度被动：

- `磐岩壁垒`：每场战败少掉 `1` 血
- `迅刃风暴`：每场首次用剪刀赢下小局时额外获得 `1` 金币
- `秘纸教团`：每个商店阶段第一次刷新免费，之后从 `1` 金开始递增

这套被动目前属于“轻度差异化”，主要是增加风格区分和局内决策感，整体数值还需要继续做平衡测试。

## 联机使用方法

### 房主

1. 启动程序
2. 输入昵称
3. 选择阵营
4. 填写端口，默认是 `5555`
5. 选择房间人数，当前支持 `2-8` 人
6. 点击“创建房间并加入”
7. 把界面里显示的 `IP:端口` 发给其他玩家

### 加入者

1. 启动程序
2. 输入昵称
3. 选择阵营
4. 填写房主的 `IP`
5. 填写房主使用的端口
6. 点击“加入联机房间”

### 开局机制

- 玩家满员后会自动开始
- 房主不需要额外点击“开始”
- 大厅中可以复制分享地址

### 本机测试

如果你想在同一台电脑上做本地测试，可以使用：

```text
127.0.0.1:5555
```

### 跨公网联机

当前默认场景是局域网联机。  
如果你希望跨公网游玩，需要自行处理：

- 路由器端口映射
- 内网穿透
- 防火墙放行对应端口

## 界面说明

### 首页

- 选择阵营
- 创建房间
- 加入房间
- 查看当前阵营被动
- 查看玩法说明

### 联机大厅

- 查看当前玩家列表
- 查看玩家生命值与阵营身份
- 复制房间地址
- 等待房间满员后自动开局

### 对战阶段

- 先选战斗道具，再选出拳
- 如果某种拳型数量为 `0`，对应按钮不可用
- 如果当前没有可用出拳，系统会自动跳过本小局
- 回合回放会显示比分变化、道具触发和阵营被动触发

### 商店阶段

- 购买当前槽位内容
- 刷新商店
- 结束商店阶段
- 若你是 `秘纸教团`，每个商店阶段首刷会显示为免费

### 战报与滚动

- 页面整体支持滚动
- 战报日志区域也支持内部滚动
- 在非全屏窗口下依然可以查看完整日志
